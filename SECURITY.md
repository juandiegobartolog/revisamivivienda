# Seguridad

Este proyecto maneja potencialmente información personal y ubicaciones de viviendas afectadas.

Si encuentras una vulnerabilidad que pueda exponer datos privados, permitir acceso no autorizado o comprometer una instancia desplegada, evita publicarla inicialmente en un issue público. Contacta de forma privada al responsable de la instancia o mantenedor del repositorio.

Nunca publiques en issues o pull requests:

- credenciales;
- direcciones exactas de ciudadanos;
- teléfonos o correos privados;
- fotografías reales que contengan datos personales;
- dumps de bases de datos de producción.
