# Contribuir a Revisa Mi Vivienda

Gracias por querer aportar.

## Principios

Las contribuciones deben priorizar:

1. seguridad de las personas;
2. privacidad y minimización de datos;
3. claridad para ciudadanos en situaciones de emergencia;
4. accesibilidad y rendimiento móvil;
5. trazabilidad de cambios;
6. evitar presentar revisiones comunitarias como certificaciones oficiales.

## Antes de enviar un cambio

- No incluyas credenciales, datos personales ni fotografías reales de reportes.
- Mantén nombres de tablas y columnas en `snake_case` y minúsculas.
- Valida permisos y reglas de negocio en backend, no solo en JavaScript.
- Mantén toda la interfaz de usuario en español salvo que exista una estrategia formal de internacionalización.
- Ejecuta `php -l` sobre los archivos PHP modificados.

## Pull requests

Describe:

- el problema que resuelve;
- la lógica de negocio afectada;
- cómo fue probado;
- cualquier cambio de base de datos requerido;
- implicaciones de privacidad o seguridad.
